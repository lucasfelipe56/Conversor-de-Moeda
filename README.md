# 🪙 Conversor de Moedas

Um projeto simples e eficiente desenvolvido para converter o Real (BRL) em moedas de outras regiões do mundo, utilizando taxas de câmbio atualizadas em tempo real.

---

## 🎯 Para que serve?
O objetivo principal deste projeto é facilitar a conversão rápida de valores em **Real (BRL)** para moedas estrangeiras. Ele resolve o problema de quem precisa saber o valor atualizado de uma moeda sem precisar fazer contas manuais ou buscas complexas.

## 🧠 O que eu aprendi?
Desenvolver este projeto foi uma excelente oportunidade para consolidar conceitos fundamentais de programação. Meus principais aprendizados foram:

* **Manipulação de Funções:** Melhorei meus conhecimentos na estruturação e reutilização de código usando `functions`.
* **Interação com o Usuário:** Aprendi a capturar, validar e processar os dados e valores disponibilizados pelos usuários no sistema.
* **Consumo de APIs:** Tive meu primeiro contato na integração com APIs externas para buscar o preço atualizado das moedas em tempo real.

## 🛠️ Tecnologias Utilizadas
* Linguagem utilizada JavaScript
* API de Cotação de Moedas
